# 福井エリア 来店予約ウォッチ

福井県内のソフトバンク・ワイモバイル店舗の来店予約空き状況を、
店舗・日付・時間帯ごとに表示するWebアプリです。

## 対象店舗

- RA02: ソフトバンクMEGAドン・キホーテUNY敦賀
- R306: ソフトバンク鯖江
- R316: ソフトバンク鯖江中央
- R311: ソフトバンクアピタ福井大和田
- WA2L: ワイモバイルアピタ福井大和田
- R307: ソフトバンク福井運動公園
- R315: ソフトバンクMEGAドン・キホーテUNY福井
- R323: ソフトバンク二の宮

## 現在の取得条件

- 対象店舗: 上記8店舗から選択
- 来店目的: 契約内容確認・変更
- 所要時間: 30分
- 表示期間: 公式予約画面が返す直近14日
- 自動更新: 5分間隔
- 同一サーバー内のキャッシュ: 5分

来店目的によって所要時間と空き状況が変わるため、現在は上記の条件に固定しています。

## 起動

```powershell
npm install
npm run dev
```

ブラウザで `http://localhost:3000` を開きます。

初回取得には10〜30秒ほどかかります。Chromeが通常と異なる場所にある場合は、
`CHROME_PATH` に実行ファイルの絶対パスを指定してください。

## スマートフォンへ一時公開

アプリを起動した状態で、別のターミナルから次を実行します。

```powershell
npm run share
```

表示された `https://...trycloudflare.com` のURLをスマートフォンで開きます。
このURLは一時公開用で、PCまたはアプリを停止すると利用できなくなります。

## PCを起動しない常設公開

GitHub PagesとGitHub Actionsを使う構成を用意しています。

- `public-site/`: スマートフォン向けの公開ページ
- `scripts/generate-static-data.ts`: 8店舗の最新データを取得
- `.github/workflows/deploy-pages.yml`: 毎時17分・47分に自動取得して公開

GitHubの公開リポジトリへプッシュし、リポジトリの
`Settings > Pages > Build and deployment > Source` を `GitHub Actions`
にすると公開されます。以後はPCを停止していても約30分ごとに更新されます。
GitHubの定期実行状況により、更新が数分遅れる場合があります。

公開ページのデータを手元で更新する場合:

```powershell
npm run static:collect
```

## ビルド

```powershell
npm run build
npm run start
```

## 注意事項

- 公式サイトを通常のブラウザ操作で開き、表示されたデータを読み取ります。
- 公式サイトの画面構成が変更された場合は取得処理の更新が必要です。
- アクセス集中を避けるため、5分キャッシュと手動更新の最短間隔を設けています。
- 表示は取得時点の情報です。予約確定はソフトバンク公式画面で行ってください。
- 公開運用する場合は、事前にサイト利用条件と運営元の許可範囲を確認してください。
